# SOAP — göğüs hastalıkları ayaktan kontrol (GOGUS-EXCEPTIONAL-01)

## Kilitler (asla ihlal etme)
- Uydurma **doz / mcg / puff** yok. İnhaler yalnız **sınıf** düzeyinde (ICS-LABA, LAMA, SABA…).
- **Tanı kilidi yalnız hekimde.** CAT, mMRC, GOLD grubu/evre = karar desteği; "KOAH tanısı kondu" yazma.
- Tam **SFT cihaz entegrasyonu yok**; elle girilen FEV1/FVC varsa sayı olarak aktar, yorumu hekime bırak.
- **gogus-cerrahisi** (toraks OR, lobektomi, VATS planı) bu bölümün ürünü değildir — önerme.
- Masif hemoptizi, hipoksi + solunum sıkıntısı, ani göğüs ağrısı + nefes darlığı, stridor → **112 / acil**; portal mesajı ile yönetme.
- Canlı Medula e-imza yok; rapor taslağı "hekim imzalar" dilinde.

## Öznel (S)
- Öksürük, balgam (renk/miktar/kan), nefes darlığı (efor / istirahat), hırıltı, göğüs ağrısı, ateş, kilo kaybı.
- Sigara / paket-yılı, meslek / toz / duman maruziyeti, bilinen astım/KOAH (hekim tanısı).
- Alevlenme öyküsü (son 12 ay orta / yatışlı) — sayı hekimden.

## Nesnel (O)
- SpO₂, solunum sayısı, ateş, dinleme bulguları (hekim kaydı).
- CAT / mMRC (varsa) — skor + "karar desteği" etiketi.
- Spirometri (elle girilmişse): FEV1/FVC, FEV1% — cihaz entegrasyonu iddiası yok.

## Değerlendirme (A)
- Ayırıcıları listele; **tek tanı kilitleme**.
- GOLD grubu / astım kontrol düzeyi varsa "karar desteği" diye etiketle.
- Kırmızı bayrak varsa açık yaz; hekim onayı olmadan vizit kapatma dili kullanma.

## Plan (P)
- İnhaler **sınıfı** + teknik kontrol; doz yazma.
- Yazılı aksiyon planı (yeşil/sarı/kırmızı) hatırlatması — doz hekim reçetesinde.
- Spirometri / kontrol / tütün bırakma (ALO 171) görevleri.
- SGK solunum raporu gerekiyorsa taslak + SUT kontrol listesi (e-imza yok).
