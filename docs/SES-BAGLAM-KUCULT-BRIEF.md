## Measured, today, real conversations (Kaan, live test)
Both the ElevenLabs (Kardiyoloji) and the Fish (Pediatri/Ayşe) voice paths show the same problem — confirmed shared root cause, not transport-specific:
- `ai_token_kullanim` for `sohbet-uzman` calls during live voice conversations: input_tokens 6,700–20,000, cache_read up to 22,593 — for ordinary conversational turns, including plain greetings ("nasılsınız").
- Time from turn dispatch to the model's first sentence: 4.1–14.1 seconds (measured via the Fish path's new `gecikme` logging — `ilk_soz_ms` in `ses_kullanim`). Kaan's own words: "her response is very slow," confirmed on both voice paths.
- Root cause located precisely: `lib/asistan/ayseCevapla.ts` puts the FULL active-patient dossier text (`paket.metin`, unabridged) into the prompt's "kararlı" block on EVERY turn where a patient is in focus — a casual "nasılsınız" gets the exact same multi-thousand-token dossier as a deep clinical query. The existing İlk-10 evidence mechanism (`soruTuruBul` → `kanitBlogu`) is ALREADY correctly conditional and is not the problem — do not touch it.

## The fix — principle
Voice is a real-time channel; text/chat is not. Apply the same "short for voice, full for text" split that already exists for specialty knowledge (personaEngine.ts, 2026-08-14) to the PATIENT DOSSIER:
- **kanal: 'ses'**: the always-present baseline shrinks to a short, safety-complete summary — NOT the full dossier body. It must still contain, unconditionally, every safety-relevant fact today's rules require Ayşe to never omit: active medications and known interactions/contraindications, allergies, any open red-flag/alarm finding, the patient's name/age/weight-for-dosing basics. Everything else (full visit history, full lab tables, full vaccine ledger, full growth curve data) is dropped from the ALWAYS-SENT block and reached instead through the EXISTING conditional evidence mechanism (soruTuru/kanitBlogu) when the doctor actually asks something that needs it — exactly as deep clinical questions already work today.
- **kanal: 'yazili' (chat/text)**: unchanged. Full dossier stays, as today.
- This is a safety-sensitive change. Do not guess which facts are "safety-relevant" — read the existing gerçeklik koruması / proaktif uyarı rules already in personaEngine.ts and ayseCevapla.ts (grep for "proaktif", "ASLA", "uyar") to enumerate exactly what must never be silently dropped, and write it down in the PR description.
