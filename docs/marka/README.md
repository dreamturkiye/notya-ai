# Notya brand assets

Vector redraw of the Notya logo in the warm "option B" palette (Kaan, 2026-11-17), used on the Pediatri Pratik Kartı and for marketing.

- `notya-logo-b-acik.*` — full logo (heart + "Notya.io") for light backgrounds
- `notya-logo-b-koyu.*` — full logo for dark backgrounds
- `notya-isaret-b-acik.*` / `notya-isaret-b-koyu.*` — heart mark only (profile pictures, favicons, small spaces)

Colours: pine `#0a4a47` / `#0e6b66`, coral `#e5765a`, sunflower `#f1b544`, cream `#fbf6ee`. Wordmark font: Poppins SemiBold.
The marketing copy of the Pratik Kartı is `docs/pazarlama/pediatri-pratik-karti-2026.pdf`; its source and build script live in the notya-growth repo (`scripts/build-pratik-kart.mjs`).
