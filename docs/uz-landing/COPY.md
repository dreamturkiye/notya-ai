# Uzbekistan landing page: copy

> **The Uzbek and Russian text in this file is machine-written.** It was written by Claude on 2026-10-08, not by a native speaker and not by a clinician. **A native speaker must read every line before the page goes public** (`docs/COUNTRY-PACK-CHECKLIST.md`, E11 and K1). Until then the page stays hidden from search engines and sign-up stays by invitation only.

Two versions follow, each in Uzbek (Latin script) and Russian, with an English translation beside every line so that Kaan can read both without knowing either language.

- **Version A, conventional.** Calm, descriptive, close to how the product is described to doctors today. **This is the version the page is built with** (`countries/uz/acilis/icerik.ts`). The tables for version A are generated from that file, so they are exactly what the page shows.
- **Version B, bolder.** Shorter, promise-led headlines for the same sections. Not built. To switch, replace the headline and body lines in `icerik.ts` with the lines below; the form, the buttons and the cards stay as in version A.

**Waits on Kaan:** the choice between A and B, and a native reviewer for whichever is chosen (`docs/OPEN-COMMITMENTS.md`, NOTYA-ULKE-01h).

## Rules this copy follows

Checked automatically for the built page and for every Uzbek and Russian line in this file (`countries/uz/acilis/acilis.test.ts`):

- No price. The page says "request a price".
- No public demo and no offer of one.
- No claim of a connection to any state system, in Uzbekistan or elsewhere.
- Nothing of Türkiye: none of its state or payer systems, its data law, its currency, its clinical references, and not the Turkish name of the assistant.
- The assistant is referred to generically ("yordamchi", "помощник"). Her local name and background are not decided.
- No mention of the voice profile or of image evaluation: both are switched off in Uzbekistan.
- No claim about where data is stored or how it is protected: that waits for the legal gates (checklist A1, I6).
- Only capabilities the product already has, described by what they give the doctor, at the same level of discretion as the Turkish pages.

## Notes for the native reviewer

- **Spelling.** Uzbek uses the modifier letter ʻ (U+02BB) in oʻ and gʻ, and ʼ (U+02BC) for the tutuq belgisi (maʼlumot). Many sites type a plain apostrophe instead. Say which one doctors expect to see.
- **Terms to confirm (Uzbek):** "qabul" for a visit; "tibbiy yozuv" and "qabul yozuvi" for the note; "xulosa" for the conclusion; "koʻrik" for the examination and "keyingi koʻrik" for the follow-up; "bemor kartasi" for the chart; "registrator" for the front desk; "hamkasb maslahati" for a consultation between doctors; "yordamchi" for the assistant; "taklif kodi" for the invitation code; "hisob" for an account.
- **Terms to confirm (Russian):** "приём", "запись приёма", "заключение", "повторный осмотр", "карта пациента", "регистратор", "консультация коллеги", "помощник", "код приглашения", "учётная запись".
- **Register.** Formal "siz" / "вы" throughout. Check that it does not read as translated.
- **Script.** Uzbek is in Latin script only. Cyrillic Uzbek is declared in the country pack but not written; say whether the pilot needs it.
- Russian headlines fall back to the reader's own serif typeface: the display typeface of the page has no Cyrillic letters.
