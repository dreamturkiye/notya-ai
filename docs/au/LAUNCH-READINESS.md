# Australian launch readiness (AU-LAUNCH-01, 2026-10-24, branch `au-launch` off `release/au`)

Audit of the Australian build (au.notya.io) against Kaan's regulatory brief of 2026-10-24, by reading the code and running the country test suite. **This is not legal or regulatory advice and not a finding that any law is met.** A status of DONE or FIXED NOW means "the code does what the row says"; it never means "compliant". Nothing was click-tested in a browser, no deployment environment was read, and no model output was sampled (see "Could not verify").

Status words: DONE (already true, checked in code) · FIXED NOW (changed in this job) · OPEN-Kaan · OPEN-Claude · NEEDS-LEGAL · NEEDS-CLINICIAN · NEEDS-TGA-ADVICE.
