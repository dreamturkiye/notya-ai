# Ayşe — the 100 most common doctor questions on the PRODUCTION brain, GPT-6 Luna (2026-09-29, `feat/ayse-100`)

Follow-up to `docs/denetim/2026-09-29-ayse-100.md` (that run fell to Sonnet 5 because no OpenRouter key was available locally). This run exercises the model production selects: `lib/ai/modeller.ts` `MODEL_HIZLI = 'openai/gpt-6-luna'` (NOTYA_MODEL_HIZLI unset → default, exactly as in Vercel), through the same `lib/ai/cagir.ts` → `lib/ai/saglayici.ts` OpenRouter path (`provider.data_collection: deny`, prompt caching). Nothing was hard-coded in the harness.

Doctor account: Dr. Gökhan Mamur (pediatri, read-only — 4 charts: A.Y. (5 y, atypical pneumonia 25 Eylül), R.D. (2 y 7 m, right AOM 28 Eylül US / 29 Eylül TRT), the synthetic QA baby U.T. (15 visits, aşı, lab) and the empty chart O.B.). Names, parent names and phone numbers are masked here; the raw runs (`.denetim-out/ayse-100-luna-p1.jsonl`, `-p2.jsonl`) are gitignored and stay on Kaan's Mac. Timezone America/New_York, "today" 2026-09-29 (evening US = 30 Eylül TRT).

## Method

- Harness `scripts/ayse-denetim/yuz.mts`, in-process `ayseCevapla`, dry-run Supabase client (reads pass through doctor-scoped, every write swallowed — 50 × `ai_kullanim`, `asistan_actions`, `doktor_iliski`, `doctor_preferences`, 5 × chart cache). Channel `sohbet`, persona `aysekaya`, 103 questions in 6 sessions (S1 A.Y. named + unnamed follow-ups, S2 R.D. in ASR style, S3 U.T., S4 page patient, OPS calendar/operations, NEG edge cases). Rubric per question: required regexes, forbidden phrases (deflections "menüden kontrol edin / erişemiyorum", other patients' names), plus a hand read of every model answer.
- **Sonnet disabled.** New audit kill-switch `NOTYA_KORUYUCU_KAPALI=1` (`lib/ai/cagir.ts`, `31ae80ea`): every G1 transport / G2 quality / G4 breaker fall that would have reached the koruyucu throws `AiCagriHatasi(599, luna_fail:<neden>:<altKod>)` and is graded as a FAIL of that question. The harness sets it by default (`--koruyucu acik` restores production behaviour) and logs every LLM call: model, HTTP status, `finish_reason`, text / tool-call shape, latency, tokens, cached tokens, OpenRouter `usage.cost`.
- First pass: all 103 once (51 Luna calls). Fixes. Second pass: 20 questions (the failures + every question the fixes touch + the session openers they need for context) — 13 Luna calls. 64 calls in all (budget: ≤ 190).
