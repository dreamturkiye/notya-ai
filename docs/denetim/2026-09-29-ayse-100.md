# Ayşe — the 100 most common doctor questions (2026-09-29, `feat/ayse-100`)

Doctor account: Dr. Gökhan Mamur (pediatri, read-only — 4 charts on the account: two real patients A.Y. (5 y, atypical pneumonia 25 Eylül) and R.D. (2 y, right AOM 29 Eylül), the synthetic QA baby U.T. (15 visits, vaccines, labs) and an empty chart O.B.). Patient names are masked in this file; the raw run (`.denetim-out/ayse-100-p1.jsonl`) is gitignored and stays on Kaan's Mac. Timezone America/New_York, "today" 2026-09-29 (evening US = 30 Eylül TRT — the search layer still windows in TRT, see ledger).

## Method

- Harness `scripts/ayse-denetim/yuz.mts` calls `ayseCevapla` **in-process** with a dry-run Supabase client: every read is doctor-scoped and passes through, every write (`asistan_sessions`, `asistan_actions`, `doctor_preferences`, `doktor_hafiza`, `ai_kullanim`, chart cache…) is swallowed; the assistant session lives in memory so follow-ups keep their context. Nothing was created or changed in production. Channel `sohbet`, persona `aysekaya`, 103 questions in 6 sessions: S1 A.Y. named then 23 unnamed follow-ups (İlk-10 + card questions), S2 R.D. in ASR style (no diacritics, "Ayşe, …" address), S3 U.T. (aşı / lab / büyüme deep), S4 page patient (patientId, never named), OPS calendar/operations, NEG edge cases. Question set: `scripts/ayse-denetim/sorular-100.json` (automatic rubric per question: required regexes, forbidden phrases incl. "menüden kontrol edin / erişemiyorum" deflections and other patients' names).
- **Model caveat.** `OPENROUTER_API_KEY` is a *sensitive* Vercel variable: `vercel env pull` writes it empty and the API cannot decrypt it, so GPT-6 Luna could not be exercised locally. With no OpenRouter key the brain falls to the direct Anthropic path, so the model turns below ran on **Sonnet 5 (the koruyucu)** with the production prompts, chart blocks and deterministic layers unchanged. 51 of the 103 questions never reach a model (deterministic layer) — those results hold for Luna as well. **The Anthropic credit balance ran out at question 67** ("credit balance is too low"); the 10 model questions after that are ERR, not graded.
- Verdict = automatic rubric; every FAIL and every model answer was also read by hand.
